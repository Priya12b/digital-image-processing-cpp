# Digital Image Processing in C++

A collection of pixel-level digital image processing implementations developed in C++.

The implementations focus on understanding the underlying algorithms rather than relying on high-level image-processing libraries.

## Topics Covered

- Digital image representation
- Pixel-level transformations
- Image coordinate systems
- Geometric transformations
- Image sampling
- Image quantization
- RGB, HSV and YCbCr color spaces
- Image histograms
- Histogram equalization
- From 3D scene to digital image

## Technologies

- C++
- Python
- NumPy
- Matplotlib
- stb_image
- stb_image_write

## Approach

The core image operations are implemented at the pixel level. Python, NumPy and Matplotlib are used mainly for visualization where required.

## Project Structure

Each numbered directory contains the implementation and generated outputs for one image-processing concept.

## Note

This repository is intended to document my implementation and understanding of fundamental digital image processing techniques.
